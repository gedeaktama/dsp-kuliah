Kekuatan Luar Biasa Sistem LTI: 'Sidik Jari' Respons Impuls

Slide 2 / 14

📘 Mengapa Fokus Utama DSP Ada pada Sistem LTI?

  • Keajaiban Karakterisasi Total: Sebuah sistem LTI (Linear Time-Invariant), serumit apapun sirkuit atau algoritmanya di dalam black-box, dapat dipetakan 100% secara sempurna hanya dengan mengamati responsnya terhadap satu sinyal uji sederhana: Impuls Satuan delta[n]!
  • Jika kita mengetahui respons impuls h[n], kita dijamin dapat memprediksi output y[n] terhadap masukan x[n] APAPUN di alam semesta ini tanpa terkecuali.
  • Tidak ada kelas sistem lain di luar LTI yang memiliki sifat deterministik seanggun ini.

🚀 Dua Representasi Utama Sistem LTI

  • 1. Representasi Non-Rekursif (Respons Impuls h[n]): Menggambarkan sistem melalui operasi penjumlahan berbobot sampel masa lalu dan sekarang (ciri khas filter FIR).
  • 2. Representasi Rekursif (Persamaan Beda LCCDE): Menggambarkan sistem melalui hubungan masukan x[n] dan umpan balik riwayat keluaran masa lalu y[n-k] (ciri khas filter IIR).
  • Kedua sudut pandang ini saling melengkapi dalam perancangan filter dan kontrol cerdas.

Dekomposisi Masukan & Penurunan Formula Konvolusi

Slide 3 / 14

Penurunan Matematis dari Impuls Menuju Konvolusi

$$x[n] = \sum_{k=-\infty}^{\infty} x[k] \delta[n - k] \implies y[n] = \mathcal{T}\{x[n]\} = \sum_{k=-\infty}^{\infty} x[k] h[n - k] = x[n] * h[n]$$

📐 Keterangan Variabel & Makna Fisik

  • x[n]: Sinyal masukan sebarang yang diuraikan menjadi rangkaian impuls terboboti x[k]*delta[n-k].
  • T[ . ]: Operator transformasi sistem yang bersifat Linear dan Time-Invariant.
  • h[n] = T{ delta[n] }: Respons impuls (respons sistem ketika masukan adalah delta[n]).
  • h[n - k] = T{ delta[n - k] }: Respons impuls yang bergeser sejauh k karena sifat Time-Invariance.
  • Simbol bintang (*): Operator konvolusi diskrit (bukan perkalian biasa!).

🔢 Contoh Perhitungan Bertahap

  • Langkah 1 (Representasi Sifting): Tuliskan input sebagai jumlahan impuls: x[n] = sum x[k] delta[n-k].
  • Langkah 2 (Sifat Linearitas): Masukkan operator T ke dalam jumlahan: y[n] = sum x[k] T{ delta[n-k] }.
  • Langkah 3 (Sifat Time-Invariance): Karena T{ delta[n] } = h[n], maka T{ delta[n-k] } = h[n-k].
  • Langkah 4 (Hasil Akhir): y[n] = sum_{k=-inf}^{inf} x[k] h[n-k]. Inilah Persamaan Konvolusi Diskrit!

Kausalitas & Kestabilan BIBO Sistem LTI Berbasis h[n]

Slide 4 / 14

📘 Syarat Mutlak Kausalitas Sistem LTI

  • Teorema Kausalitas LTI: Sistem LTI bersifat kausal JIKA DAN HANYA JIKA respons impuls bernilai tepat nol untuk semua waktu sebelum origin:
  • h[n] = 0 untuk seluruh n < 0.
  • Makna Fisik: Sistem tidak boleh memberikan respons apapun sebelum rangsangan impuls diberikan pada waktu n = 0.
  • Sekuens yang memenuhi h[n] = 0 untuk n < 0 disebut sebagai Sekuens Kausal.

🚀 Syarat Mutlak Kestabilan BIBO Sistem LTI

  • Teorema Stabilitas BIBO: Sistem LTI stabil BIBO jika dan hanya jika respons impulsnya bersifat absolutely summable (dapat dijumlahkan mutlak secara berhingga):
  • S = sum_{n=-inf}^{inf} |h[n]| < inf.
  • Bukti Cepat: |y[n]| = |sum x[k] h[n-k]| <= sum |x[k]| |h[n-k]| <= Mx * sum |h[m]|.
  • Karena Mx berhingga, maka y[n] dijamin berhingga jika sum |h[m]| < inf.

Contoh Uji Kestabilan LTI: Filter Stabil vs Tidak Stabil

Slide 5 / 14

📘 Kasus A: h[n] = (0.5)^n u[n] (Filter Eksponensial Kausal)

  • Langkah 1 (Uji Kausalitas): Karena terdapat perkalian u[n], maka h[n] = 0 untuk n < 0. Sistem TERBUKTI KAUSAL.
  • Langkah 2 (Uji Stabilitas): Evaluasi jumlahan mutlak:
  • sum_{n=-inf}^{inf} |h[n]| = sum_{n=0}^{inf} (0.5)^n.
  • Langkah 3: Gunakan rumus deret geometri tak terhingga S = a / (1 - r):
  • S = 1 / (1 - 0.5) = 2 < inf.
  • Kesimpulan: Karena jumlahan berhingga (S = 2), SISTEM TERBUKTI STABIL BIBO!

🚀 Kasus B: h[n] = u[n] (Sistem Akumulator Ideal)

  • Langkah 1 (Uji Kausalitas): h[n] = 0 untuk n < 0. Sistem bersifat kausal.
  • Langkah 2 (Uji Stabilitas): Evaluasi jumlahan mutlak:
  • sum_{n=0}^{inf} |u[n]| = sum_{n=0}^{inf} 1 = 1 + 1 + 1 + ... = inf.
  • Langkah 3: Jumlahan menghasilkan nilai divergen tak hingga.
  • Kesimpulan: Sistem Akumulator murni TIDAK STABIL BIBO secara umum (meskipun untuk input berenergi berhingga tertentu ia dapat menghasilkan nilai berhingga).

Klasifikasi Durasi Sistem LTI: FIR vs IIR

Slide 6 / 14

📌 FIR (Finite Impulse Response)

  • Respons impuls h[n] bernilai tepat nol di luar interval waktu berhingga 0 <= n <= M.
  • Panjang koefisien berhingga (jumlah tap = M + 1).
  • Selalu Stabil BIBO: Karena jumlahan berhingga dari bilangan terbatas pasti selalu berhingga!
  • Mampu memiliki karakteristik Linear Phase murni (tanpa distorsi bentuk gelombang).

📌 IIR (Infinite Impulse Response)

  • Respons impuls h[n] berlangsung selamanya (tak terhingga) seiring berjalannya waktu, biasanya meluruh eksponensial.
  • Menggunakan loop umpan balik (feedback) dari keluaran sebelumnya.
  • Efisiensi Komputasi Tinggi: Membutuhkan jauh lebih sedikit koefisien dibanding FIR untuk mencapai ketajaman cutoff yang sama.
  • Risiko: Dapat menjadi tidak stabil jika koefisien pole berada di luar lingkaran satuan.

📌 Analogi Fisik Sederhana

  • FIR dianalogikan seperti memukul balok kayu: getaran langsung berhenti seketika dalam beberapa ketukan.
  • IIR dianalogikan seperti membunyikan lonceng perunggu: bunyi dengung bergetar terus-menerus dan meluruh perlahan seiring waktu (decay).

Persamaan Beda Linear Koefisien Konstan (LCCDE)

Slide 7 / 14

Formulasi Umum Persamaan Beda Sistem LTI

$$\sum_{k=0}^{N} a_k y[n - k] = \sum_{k=0}^{M} b_k x[n - k] \quad \iff \quad y[n] = \frac{1}{a_0} \left( \sum_{k=0}^{M} b_k x[n - k] - \sum_{k=1}^{N} a_k y[n - k] \right)$$

📐 Keterangan Variabel & Makna Fisik

  • N: Orde sistem (menunjukkan jumlah elemen tunda memori umpan balik output).
  • M: Jumlah elemen tunda masukan sinyal input x[n].
  • b_k: Koefisien feedforward (mengatur kontribusi sinyal masukan saat ini dan masa lalu).
  • a_k: Koefisien feedback (mengatur kontribusi sinyal keluaran masa lalu). Umumnya dinormalisasi a_0 = 1.
  • Jika seluruh a_k = 0 untuk k >= 1: Sistem menjadi FIR (tanpa umpan balik).
  • Jika minimal ada satu a_k != 0 untuk k >= 1: Sistem menjadi IIR (rekursif).

🔢 Contoh Perhitungan Bertahap

  • Contoh LCCDE Orde-1: y[n] - 0.8 y[n-1] = 2 x[n].
  • Bentuk Rekursif Komputasi: y[n] = 0.8 y[n-1] + 2 x[n].
  • Hitung respons impuls h[n] dengan memberikan input x[n] = delta[n] dan asumsi kondisi awal nol (y[-1] = 0):
  • n = 0: y[0] = 0.8(0) + 2(1) = 2.
  • n = 1: y[1] = 0.8(2) + 2(0) = 1.6.
  • n = 2: y[2] = 0.8(1.6) + 0 = 1.28 = 2 * (0.8)^2.
  • Pola Umum: h[n] = 2 * (0.8)^n u[n]. Terbukti respons impuls berlangsung tak terhingga (IIR)!

Komponen Pembentuk Diagram Blok Sistem DSP

Slide 8 / 14

📌 1. Unit Delay Element (z^-1)

  • Menunda sinyal tepat 1 periode sampel: y[n] = x[n - 1].
  • Diimplementasikan menggunakan register flip-flop hardware atau variabel pointer memori RAM.
  • Notasi z^-1 berasal dari domain Transformasi-Z.

📌 2. Multiplier / Gain (b_k, a_k)

  • Mengalikan sinyal yang lewat dengan sebuah konstanta bobot skalar: y[n] = c * x[n].
  • Diimplementasikan oleh sirkuit hardware MAC (Multiply-Accumulate unit) berkecepatan tinggi pada prosesor DSP.

📌 3. Adder / Summer (+)

  • Menjumlahkan dua atau lebih jalur sinyal yang masuk secara simultan: y[n] = x1[n] + x2[n].
  • Kombinasi ketiga komponen ini membentuk struktur Direct Form I, Direct Form II, Cascade, dan Paralel.

Implementasi Python: Simulasi Respons Sistem dengan SciPy

Slide 9 / 14

📖 Penggunaan scipy.signal.lfilter & dimpulse

  • scipy.signal.lfilter(b, a, x) adalah fungsi standar industri untuk mengeksekusi persamaan beda LCCDE secara efisien.
  • Vektor b merepresentasikan koefisien pembilang [b0, b1, ..., bM].
  • Vektor a merepresentasikan koefisien penyebut [a0, a1, ..., aN].
  • Fungsi scipy.signal.dimpulse() menghitung respons impuls diskrit secara analitis.
Python Implementation (NumPy / SciPy) 
import numpy as np
import matplotlib.pyplot as plt
from scipy.signal import lfilter, dimpulse, dstep

# Definisikan sistem: y[n] - 0.7 y[n-1] = 0.5 x[n] + 0.3 x[n-1]
b = [0.5, 0.3]     # Koefisien masukan (feedforward)
a = [1.0, -0.7]    # Koefisien keluaran (feedback, a0=1)

# Hitung respons impuls h[n] sebanyak 20 sampel
system = (b, a, 1.0) # format transfer function diskrit
t, h = dimpulse(system, n=20)
h = np.squeeze(h)

plt.figure(figsize=(9, 4))
plt.stem(range(len(h)), h, linefmt='b-', markerfmt='bo', basefmt='r-')
plt.title('Respons Impuls h[n] Sistem LTI Orde-1 (Meluruh Eksponensial)')
plt.xlabel('Indeks n'); plt.ylabel('Amplitudo h[n]')
plt.grid(True, linestyle='--', alpha=0.6)
plt.show()
