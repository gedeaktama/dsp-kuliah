Sekuens Waktu Diskrit sebagai Fondasi Komputasi

Slide 2 / 15

📘 Definisi Formal Sekuens Diskrit

  • Sekuens diskrit direpresentasikan sebagai fungsi x[n] di mana variabel independen n adalah bilangan bulat (n in Z = {..., -2, -1, 0, 1, 2, ...}).
  • x[n] tidak pernah terdefinisi untuk nilai n non-integer (misalnya x[1.5] tidak memiliki makna matematis).
  • Empat Mode Representasi Sinyal Diskrit: Fungsional/Persamaan Matematis, Daftar Tabular Nilai Angka, Barisan Vektor Sekuensial dengan Penanda Origin, dan Diagram Batang Stem Plot.

🚀 Notasi Vektor & Penanda Titik Origin (n = 0)

  • Notasi kurung kurawal: x[n] = {..., 2, 1, [4], 0, -1, ...} di mana simbol panah bawah atau kurung siku [ ] menandakan titik asal n = 0.
  • Jika tidak ada tanda panah/kurung siku khusus, elemen pertama secara default diasumsikan sebagai titik n = 0.
  • Durasi Berhingga (Finite-Length) vs Durasi Tak Berhingga (Infinite-Length): Panjang sekuens N sangat menentukan kebutuhan alokasi memori komputer.

Sinyal Elementer I: Unit Sample / Impuls Satuan delta[n]

Slide 3 / 15

Definisi Impuls Satuan (Kronecker Delta)

$$\delta[n] = \begin{cases} 1, & n = 0 \\ 0, & n \neq 0 \end{cases} \qquad \delta[n - k] = \begin{cases} 1, & n = k \\ 0, & n \neq k \end{cases}$$

📐 Keterangan Variabel & Makna Fisik

  • delta[n]: Fungsi impuls diskrit Kronecker bernilai tepat 1 pada origin n=0 dan 0 di semua tempat lain.
  • delta[n-k]: Impuls yang digeser sejauh k sampel ke arah kanan (time delay).
  • Perbedaan Kritis dengan Dirac Kontinu: Impuls diskrit memiliki amplitudo berhingga = 1 (bukan tak hingga), sehingga tidak menimbulkan singularitas numerik.

🔢 Contoh Perhitungan Bertahap

  • Sifat Ekstraksi / Sifting Property: x[n] * delta[n - k] = x[k] * delta[n - k].
  • Penjumlahan Sifting: sum_{n=-inf}^{inf} x[n] delta[n - k] = x[k]. Operasi ini mengambil nilai tunggal sinyal pada indeks k.
  • Dekomposisi Sinyal Sebarang: Setiap sinyal diskrit x[n] dapat dituliskan secara mutlak sebagai kombinasi linier impuls terboboti:
  • Formula Representasi: x[n] = sum_{k=-inf}^{inf} x[k] delta[n - k].
  • Inilah prinsip paling mendasar yang memungkinkan lahirnya operasi konvolusi pada sistem LTI!

Sinyal Elementer II: Unit Step u[n] dan Ramp r[n]

Slide 4 / 15

📘 Unit Step Sequence u[n]

  • Definisi Matematis: u[n] = 1 untuk n >= 0, dan u[n] = 0 untuk n < 0.
  • Representasi Sakelar: Digunakan untuk memodelkan sinyal kausal yang baru aktif menyala pada waktu n = 0.
  • Hubungan Fundamental dengan Impuls: delta[n] = u[n] - u[n - 1].
  • Akumulasi Impuls: u[n] = sum_{k=-inf}^{n} delta[k] = sum_{k=0}^{inf} delta[n - k].

🚀 Unit Ramp Sequence r[n]

  • Definisi Matematis: r[n] = n untuk n >= 0, dan r[n] = 0 untuk n < 0.
  • Hubungan dengan Unit Step: r[n] = n * u[n].
  • Representasi Integrator Diskrit: Sinyal ramp merupakan hasil akumulasi bertingkat dari sinyal unit step.
  • Aplikasi: Digunakan sebagai sinyal uji akselerasi pada sistem kendali diskrit dan estimasi kecepatan sensor gerak.

Sinyal Elementer III: Sekuens Eksponensial Real & Kompleks

Slide 5 / 15

Formulasi Sekuens Eksponensial Diskrit

$$x[n] = a^n u[n] \quad (a \in \mathbb{R}) \qquad x[n] = e^{(\sigma + j\omega_0)n} = e^{\sigma n} \big(\cos(\omega_0 n) + j\sin(\omega_0 n)\big)$$

📐 Keterangan Variabel & Makna Fisik

  • a: Parameter basis real. Jika |a| < 1 sinyal meluruh (decaying); jika |a| > 1 sinyal membesar (growing); jika a = 1 sinyal unit step.
  • sigma: Koefisien peredaman real (damping factor).
  • omega_0: Frekuensi osilasi sudut diskrit dalam radian per sampel.
  • Formula Euler: e^(j*omega_0*n) = cos(omega_0*n) + j*sin(omega_0*n).

🔢 Contoh Perhitungan Bertahap

  • Analisis Kasus 1 (0 < a < 1, misal a = 0.8): Sekuens bernilai positif dan meluruh mulus menuju nol asimtotik.
  • Analisis Kasus 2 (-1 < a < 0, misal a = -0.8): Sekuens meluruh dengan tanda berganti-ganti (berosilasi polaritas positif-negatif).
  • Analisis Kasus 3 (|a| > 1): Sinyal membesar tanpa batas (unbounded), memodelkan sistem tidak stabil.
  • Eksponensial Kompleks: Merupakan fungsi eigen dari sistem LTI diskrit, fondasi bagi Transformasi Fourier dan Transformasi-Z!

Operasi Transformasi Sumbu Waktu (Independent Variable)

Slide 6 / 15

📌 1. Pergeseran Waktu (Shifting)

  • y[n] = x[n - k].
  • Jika k > 0, sinyal mengalami keterlambatan (time delay), bergeser ke kanan.
  • Jika k < 0, sinyal mengalami kemajuan (time advance), bergeser ke kiri.
  • Contoh: Menghasilkan efek gema suara (echo/delay).

📌 2. Pembalikan Waktu (Reversal/Folding)

  • y[n] = x[-n].
  • Sinyal dicerminkan terhadap sumbu vertikal n = 0.
  • Sampel pada waktu masa depan menjadi masa lalu.
  • Merupakan langkah wajib pertama dalam operasi konvolusi analitis.

📌 3. Penskalaan Waktu (Decimation & Expansion)

  • Downsampling (Decimation): y[n] = x[M*n], mengambil setiap sampel ke-M dan membuang sampel lainnya.
  • Upsampling (Expansion): Menyisipkan L-1 angka nol di antara sampel bersebelahan.
  • Operasi krusial pada multirate DSP.

Operasi Amplitudo Sinyal (Dependent Variable)

Slide 7 / 15

📌 Penskalaan Amplitudo (Scaling)

  • y[n] = c * x[n], di mana c adalah skalar konstanta pengali.
  • Jika |c| > 1 terjadi penguatan sinyal (amplification).
  • Jika |c| < 1 terjadi pelemahan sinyal (attenuation).
  • Direalisasikan oleh komponen Multiplier pada hardware DSP.

📌 Penjumlahan & Pengurangan

  • y[n] = x1[n] + x2[n].
  • Dihitung secara paralel untuk setiap indeks n yang berkorespondensi.
  • Direalisasikan oleh komponen Adder pada sirkuit pemrosesan sinyal.
  • Contoh: Mencampur dua trek audio (audio mixer).

📌 Perkalian Sinyal (Modulasi)

  • y[n] = x1[n] * x2[n] (perkalian elemen-ke-elemen, bukan konvolusi!).
  • Aplikasi: Modulasi amplitudo (AM), windowing untuk mengurangi spectral leakage pada FFT.
  • Contoh: Mengalikan sinyal dengan window Hamming.

Dekomposisi Sinyal: Komponen Genap (Even) & Ganjil (Odd)

Slide 8 / 15

Formula Dekomposisi Simetri Sinyal

$$x[n] = x_e[n] + x_o[n] \quad \text{di mana} \quad x_e[n] = \frac{x[n] + x[-n]}{2}, \quad x_o[n] = \frac{x[n] - x[-n]}{2}$$

📐 Keterangan Variabel & Makna Fisik

  • x_e[n]: Komponen genap (symmetric/even). Memenuhi sifat x_e[-n] = x_e[n].
  • x_o[n]: Komponen ganjil (anti-symmetric/odd). Memenuhi sifat x_o[-n] = -x_o[n]. Pada origin n=0, x_o[0] selalu bernilai 0.
  • Universalitas: Setiap sinyal sebarang, tanpa perkecualian, dapat diuraikan secara unik menjadi pasangan sinyal genap dan ganjil.

🔢 Contoh Perhitungan Bertahap

  • Contoh: Diberikan sinyal kausal berhingga x[n] = { [2], 4, 6 } untuk n = 0, 1, 2.
  • Langkah 1: Bentuk sinyal hasil pencerminan x[-n] = { 6, 4, [2] } untuk n = -2, -1, 0.
  • Langkah 2: Hitung komponen genap: x_e[0] = (2+2)/2 = 2. x_e[1] = x_e[-1] = 4/2 = 2. x_e[2] = x_e[-2] = 6/2 = 3.
  • Hasil x_e[n]: { 3, 2, [2], 2, 3 } untuk n in [-2, 2].
  • Langkah 3: Hitung komponen ganjil: x_o[0] = (2-2)/2 = 0. x_o[1] = (4-0)/2 = 2, x_o[-1] = (0-4)/2 = -2. x_o[2] = 3, x_o[-2] = -3.
  • Hasil x_o[n]: { -3, -2, [0], 2, 3 } untuk n in [-2, 2]. Verifikasi: x_e[n] + x_o[n] tepat sama dengan x[n]!

Energi dan Daya Sinyal Waktu Diskrit

Slide 9 / 15

📘 Energi Sinyal Diskrit (E)

  • Definisi Matematis: E = sum_{n=-inf}^{inf} |x[n]|^2.
  • Sinyal Energi (Energy Signal): Sinyal yang memiliki energi total berhingga (0 < E < inf).
  • Implikasi: Semua sinyal dengan durasi berhingga dan amplitudo berhingga dipastikan merupakan sinyal energi.
  • Daya rata-rata untuk sinyal energi bernilai nol (P = 0) karena energi dibagi durasi waktu tak terhingga.

🚀 Daya Sinyal Diskrit (P)

  • Definisi Matematis: P = lim_{N->inf} (1 / (2N + 1)) sum_{n=-N}^{N} |x[n]|^2.
  • Sinyal Daya (Power Signal): Sinyal dengan daya rata-rata berhingga dan bukan nol (0 < P < inf). Energinya bernilai tak terhingga (E = inf).
  • Contoh Klasik: Sinyal periodik seumur hidup x[n] = A cos(omega n + theta).
  • Sifat Mutlak: Sebuah sinyal dapat berupa sinyal energi, sinyal daya, atau bukan kedua-duanya (misalnya sinyal ramp yang divergen).

Implementasi Python: Dekomposisi Sinyal Genap & Ganjil

Slide 10 / 15

📖 Strategi Penataan Sumbu Indeks Simetris

  • Untuk melakukan operasi penjumlahan sinyal x[n] dan x[-n], kedua sekuens harus didefinisikan pada rentang indeks waktu n yang identik.
  • Gunakan teknik zero-padding untuk menyelaraskan panjang array ke rentang simetris [-N, N].
  • Fungsi np.flip() digunakan untuk merefleksikan urutan elemen array secara cepat.
Python Implementation (NumPy / SciPy) 
import numpy as np
import matplotlib.pyplot as plt

def decompose_even_odd(n, x):
    # Menyelaraskan rentang indeks n agar simetris terhadap origin
    n_min, n_max = min(n), max(n)
    n_sym_max = max(abs(n_min), abs(n_max))
    n_full = np.arange(-n_sym_max, n_sym_max + 1)
    
    # Inisialisasi array sinyal penuh dengan nol
    x_full = np.zeros_like(n_full, dtype=float)
    idx_map = np.isin(n_full, n)
    x_full[idx_map] = x
    
    # Pencerminan x[-n]
    x_reversed = np.flip(x_full)
    
    # Komponen Genap dan Ganjil
    x_even = 0.5 * (x_full + x_reversed)
    x_odd = 0.5 * (x_full - x_reversed)
    return n_full, x_full, x_even, x_odd

# Uji Coba Sekuens: x[n] = 2u[n] - u[n-4]
n_test = np.arange(0, 6)
x_test = np.array([2, 2, 2, 2, 0, 0])
n_f, x_f, x_e, x_o = decompose_even_odd(n_test, x_test)
print('Indeks n:', n_f)
print('Even xe[n]:', np.round(x_e, 2))
print('Odd xo[n]:', np.round(x_o, 2))
