Repository resmi 15 modul praktikum pemrograman Python (NumPy, SciPy, Matplotlib) untuk mata kuliah Pengolahan Sinyal Digital. Terstruktur berbasis Kurikulum Outcome-Based Education (OBE) dan siap dieksekusi secara mandiri.

Seluruh script modul Python di bawah ini kompatibel dengan Python 3.9 s.d. 3.13+. Silakan install pustaka wajib sebelum menjalankan skrip:
