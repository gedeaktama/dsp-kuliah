Transisi Paradigma: Dari Domain Waktu ke Domain Frekuensi

Slide 2 / 13

📘 Keterbatasan Pandangan Domain Waktu

  • Melihat sinyal hanya pada domain waktu (amplitudo vs waktu n) seringkali seperti melihat bayangan buram. Kita melihat gelombang berosilasi, namun sulit mengetahui frekuensi apa saja yang menyusunnya.
  • Operasi konvolusi dalam domain waktu memerlukan komputasi jumlahan perkalian berulang yang sangat intensif.
  • Domain frekuensi memungkinkan kita melihat komposisi 'resep warna' frekuensi secara transparan dan jernih.

🚀 Keanggunan Sinyal Eigen Eksponensial Kompleks

  • Sinyal eksponensial kompleks x[n] = e^(j omega n) memiliki sifat adiluhung pada sistem LTI:
  • Sinyal ini adalah FUNGSI EIGEN (Eigenfunction) dari sistem LTI!
  • Artinya: Jika masukan adalah gelombang sinusoidal dengan frekuensi omega, maka keluaran sistem DIJAMIN HANYA BERUPA GELOMBANG DENGAN FREKUENSI YANG SAMA PERSIS (omega), tanpa pernah muncul frekuensi baru!
  • Sistem LTI hanya berhak mengubah dua hal: Amplitudo (gain) dan Fase (pergeseran waktu).

Penurunan Matematis Respons Frekuensi H(e^(j omega))

Slide 3 / 13

Respons Sistem Terhadap Sinyal Eigen

$$x[n] = e^{j\omega n} \implies y[n] = \sum_{k=-\infty}^{\infty} h[k] e^{j\omega(n - k)} = \left( \sum_{k=-\infty}^{\infty} h[k] e^{-j\omega k} \right) e^{j\omega n} = H(e^{j\omega}) e^{j\omega n}$$

📐 Keterangan Variabel & Makna Fisik

  • omega: Frekuensi sudut ternormalisasi diskrit (radian per sampel).
  • h[k]: Respons impuls sistem LTI dalam domain waktu.
  • H(e^(j omega)): Respons Frekuensi (Frequency Response) sistem, bernilai bilangan kompleks.
  • Magnitude Response |H(e^(j omega))|: Nilai mutlak/panjang vektor kompleks, merepresentasikan faktor penguatan atau pelemahan amplitudo pada frekuensi omega.
  • Phase Response angle H(e^(j omega)): Sudut fase vektor kompleks, merepresentasikan pergeseran sudut fase pada frekuensi omega.

🔢 Contoh Perhitungan Bertahap

  • Langkah 1: Masukkan x[n] = e^(j omega n) ke formula konvolusi y[n] = sum h[k] x[n-k].
  • Langkah 2: Faktorkan suku e^(j omega n) keluar dari sigma karena tidak bergantung pada indeks penjumlahan k.
  • Langkah 3: Bagian di dalam sigma sum_{k=-inf}^{inf} h[k] e^(-j omega k) didefinisikan sebagai H(e^(j omega)).
  • Langkah 4: Terbukti bahwa y[n] = H(e^(j omega)) * x[n]. Nilai eigen sistem adalah tepat Respons Frekuensi H(e^(j omega))!

Respons Steady-State Sinusoidal Real

Slide 4 / 13

Output Sistem LTI Terhadap Masukan Sinus Real

$$x[n] = A \cos(\omega_0 n + \theta) \implies y_{ss}[n] = A \big|H(e^{j\omega_0})\big| \cos\Big(\omega_0 n + \theta + \angle H(e^{j\omega_0})\Big)$$

📐 Keterangan Variabel & Makna Fisik

  • A: Amplitudo awal sinyal masukan.
  • omega_0: Frekuensi sinusoidal masukan tertentu.
  • theta: Sudut fase awal masukan.
  • |H(e^(j omega_0))|: Gain sistem pada frekuensi omega_0.
  • angle H(e^(j omega_0)): Pergeseran fase yang ditambahkan oleh sistem.
  • Steady-State (Kondisi Tunak): Respons jangka panjang setelah respons transien alami sistem meluruh hingga nol.

🔢 Contoh Perhitungan Bertahap

  • Contoh: Diberikan filter dengan H(e^(j omega_0)) = 2.5 e^(-j pi/3) pada omega_0 = 0.2 pi.
  • Gain: |H| = 2.5. Pergeseran Fase: angle H = -pi/3 radian (-60 derajat).
  • Masukan: x[n] = 4 cos(0.2 pi n + pi/6).
  • Hitung Amplitudo Output: A_out = 4 * 2.5 = 10.
  • Hitung Fase Output: theta_out = pi/6 - pi/3 = -pi/6 radian (-30 derajat).
  • Keluaran Tunak: y_ss[n] = 10 cos(0.2 pi n - pi/6). Perhitungan sangat cepat dan elegan tanpa perlu melakukan konvolusi waktu!

Periodisitas 2 pi & Karakteristik Simetri Respons Frekuensi

Slide 5 / 13

📌 1. Sifat Periodik 2 pi

  • H(e^(j (omega + 2 pi))) = H(e^(j omega)).
  • Karena e^(-j (omega + 2 pi) k) = e^(-j omega k) * e^(-j 2 pi k) = e^(-j omega k) * 1.
  • Implikasi: Seluruh karakteristik respons frekuensi sistem diskrit cukup diamati pada interval fundamental sepanjang 2 pi, yaitu [-pi, pi] atau [0, 2 pi].

📌 2. Simetri untuk Respons Impuls Real

  • Jika h[n] bernilai bilangan real (seperti semua filter fisik):
  • H(e^(-j omega)) = H*(e^(j omega)) (Konjugat Kompleks).
  • Magnitude bersifat Simetri Genap: |H(e^(-j omega))| = |H(e^(j omega))|.
  • Phase bersifat Simetri Ganjil: angle H(e^(-j omega)) = - angle H(e^(j omega)).

📌 3. Rentang Frekuensi Fisik

  • omega = 0 merepresentasikan frekuensi DC (0 Hz).
  • omega = pi merepresentasikan frekuensi Nyquist (Fs / 2 Hz), frekuensi osilasi tertinggi pada sistem diskrit.
  • omega = 2 pi berputar kembali ke frekuensi DC (0 Hz).

Phase Delay & Group Delay (Keterlambatan Grup)

Slide 6 / 13

Definisi Matematis Phase Delay & Group Delay

$$\tau_p(\omega) = -\frac{\angle H(e^{j\omega})}{\omega} \qquad \tau_g(\omega) = -\frac{d}{d\omega} \Big( \angle H(e^{j\omega}) \Big)$$

📐 Keterangan Variabel & Makna Fisik

  • tau_p(omega): Phase Delay (keterlambatan waktu yang dialami oleh komponen frekuensi individu).
  • tau_g(omega): Group Delay (keterlambatan waktu yang dialami oleh selubung modulasi / paket sinyal multi-frekuensi).
  • Distorsi Fase (Phase Distortion): Terjadi jika Group Delay tidak konstan terhadap frekuensi, menyebabkan berbagai komponen nada merambat dengan kecepatan berbeda sehingga bentuk gelombang rusak.
  • Linear Phase Ideal: Filter yang memiliki sudut fase garis lurus angle H(w) = -alpha * w memiliki Group Delay konstan sempurna tau_g = alpha sampel!

🔢 Contoh Perhitungan Bertahap

  • Mengapa Group Delay Krusial pada Audio & Biomedis?
  • Pada rekaman musik: Jika frekuensi bass tertunda 10 ms lebih lambat dari nada vokal akibat fase non-linier filter, musik terdengar 'berlumpur' (muddy) dan artikulasi hilang.
  • Pada sinyal EKG: Distorsi fase dapat mengubah bentuk gelombang segmen ST, memicu salah diagnosis serangan jantung oleh dokter!
  • Inilah alasan mengapa Filter FIR Fase Linier sangat dijunjung tinggi dalam rekayasa DSP.

Analisis Kasus: Moving Average Filter 3-Titik

Slide 7 / 13

📘 Persamaan Sistem & Penurunan H(e^(jw))

  • Persamaan Beda: y[n] = (1/3) [ x[n] + x[n-1] + x[n-2] ].
  • Respons Impuls: h[n] = 1/3 untuk n = 0, 1, 2; dan 0 di tempat lain.
  • Evaluasi Respons Frekuensi:
  • H(e^(jw)) = (1/3) [ 1 + e^(-jw) + e^(-j2w) ].
  • Faktorkan suku tengah e^(-jw):
  • H(e^(jw)) = (1/3) e^(-jw) [ e^(jw) + 1 + e^(-jw) ] = (1/3) e^(-jw) [ 1 + 2 cos(w) ].

🚀 Interpretasi Magnitude & Fase

  • Magnitude Response: |H(e^(jw))| = (1/3) |1 + 2 cos(w)|.
  • Pada w = 0 (DC): |H(e^j0)| = (1/3)|1 + 2(1)| = 1.0 (Gain 0 dB, sinyal DC lolos utuh).
  • Pada w = 2*pi/3: 1 + 2 cos(2*pi/3) = 1 + 2(-0.5) = 0! Terjadi notch null sempurna (sinyal teredam total).
  • Pada w = pi (Nyquist): |H(e^jpi)| = (1/3)|1 - 2| = 1/3 (Teredam menjadi 33%).
  • Phase Response: angle H(w) = -w (linier murni) dengan lompatan pi saat melewati nol. Group Delay = 1 sampel konstan!

Implementasi Python: Visualisasi freqz pada SciPy

Slide 8 / 13

📖 Fungsi scipy.signal.freqz

  • scipy.signal.freqz(b, a, worN=512) menghitung respons frekuensi H(e^(jw)) pada 512 titik frekuensi dari 0 hingga pi (frekuensi Nyquist).
  • Magnitude biasanya dikonversi ke skala logaritmik decibel: Mag_dB = 20 * log10(|H|).
  • Fase digambarkan dalam radian atau derajat dengan penanganan unwrap: np.unwrap(np.angle(H)).
Python Implementation (NumPy / SciPy) 
import numpy as np
import matplotlib.pyplot as plt
from scipy.signal import freqz

# Definisikan Moving Average 3-Titik
b = [1/3, 1/3, 1/3]
a = [1.0]

w, h = freqz(b, a, worN=1024)
w_norm = w / np.pi # Normalisasi frekuensi terhadap Nyquist (0 sampai 1)

plt.figure(figsize=(10, 4))
# Plot Magnitude (dB)
plt.subplot(1, 2, 1)
plt.plot(w_norm, 20 * np.log10(np.abs(h) + 1e-6), 'b-', lw=1.5)
plt.title('Magnitude Response (dB)'); plt.xlabel('Frekuensi Ternormalisasi (x pi rad/sampel)')
plt.ylabel('Magnitude (dB)'); plt.grid(True, alpha=0.6)

# Plot Phase (Derajat)
plt.subplot(1, 2, 2)
plt.plot(w_norm, np.unwrap(np.angle(h)) * 180 / np.pi, 'r-', lw=1.5)
plt.title('Phase Response (Derajat)'); plt.xlabel('Frekuensi Ternormalisasi (x pi rad/sampel)')
plt.ylabel('Fase (derajat)'); plt.grid(True, alpha=0.6)
plt.tight_layout(); plt.show()
