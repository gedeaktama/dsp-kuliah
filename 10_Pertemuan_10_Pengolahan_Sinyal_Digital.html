Dari DTFT Kontinu Menuju Komputasi Nyata DFT

Slide 2 / 14

📘 Kebutuhan Komputasi Praktis

  • DTFT menghasilkan spektrum kontinu X(e^jw). Namun, komputer digital dan prosesor DSP HANYA BISA menyimpan dan memproses angka-angka diskrit dalam memori berhingga.
  • Solusi Brilian: Lakukan pencuplikan (sampling) pada sumbu frekuensi kontinu omega sebanyak N titik berjarak sama sepanjang interval [0, 2 pi).
  • Lahirnya Discrete Fourier Transform (DFT): Transformasi Fourier yang diskrit dalam domain waktu DAN diskrit dalam domain frekuensi!

🚀 DFT sebagai Algoritma Paling Berpengaruh Abad Ini

  • Setiap format file multimedia modern (MP3, AAC, JPEG, MPEG-4) bergantung langsung pada DFT / DCT.
  • Sistem spektogram pengenal suara cerdas (Speech AI), equalizer audio, hingga radar modern beroperasi menggunakan komputasi DFT real-time.
  • Kehadiran algoritma Fast Fourier Transform (FFT) menurunkan beban komputasi dari ribuan jam menjadi hitungan milidetik.

Formulasi Formal DFT & Inverse DFT (IDFT)

Slide 3 / 14

Pasangan Transformasi DFT N-Titik

$$X[k] = \sum_{n=0}^{N-1} x[n] W_N^{kn} \qquad x[n] = \frac{1}{N} \sum_{k=0}^{N-1} X[k] W_N^{-kn} \qquad \Big( W_N = e^{-j\frac{2\pi}{N}} \Big)$$

📐 Keterangan Variabel & Makna Fisik

  • x[n]: Sekuens waktu berdurasi N sampel (n = 0, 1, ..., N-1).
  • X[k]: Koefisien spektral DFT pada bin frekuensi ke-k (k = 0, 1, ..., N-1).
  • W_N = e^(-j 2 pi / N): Twiddle Factor (Faktor Pemutar kompleks).
  • k: Indeks bilangan bulat bin frekuensi diskrit.
  • Faktor 1/N: Skalar normalisasi pada persamaan sintesis IDFT.

🔢 Contoh Perhitungan Bertahap

  • Pemetaan Indeks Bin ke Frekuensi Fisik Riil:
  • Setiap indeks k berkorespondensi tepat dengan frekuensi fisik dalam Hertz:
  • f_k = k * (Fs / N) (Hz) \qquad \text{atau} \qquad \omega_k = \frac{2\pi k}{N} \text{ (rad/sampel)}.
  • Resolusi Frekuensi Fundamental (Jarak antar bin bersebelahan):
  • \Delta f = \frac{F_s}{N} = \frac{1}{T_{\text{record}}} \quad \text{(Hz)}.
  • Kaidah Emas: Resolusi frekuensi HANYA DITENTUKAN oleh durasi total rekaman waktu (T_record = N * Ts), bukan sekadar frekuensi sampling!

Kompleksitas Komputasi: DFT Langsung vs Algoritma FFT

Slide 4 / 14

📌 DFT Langsung: O(N^2)

  • Menghitung N titik output X[k], masing-masing membutuhkan N perkalian kompleks dan N-1 penjumlahan kompleks.
  • Total Perkalian Kompleks: N^2.
  • Untuk N = 1024 sampel: Membutuhkan ~1,048,576 perkalian kompleks.
  • Untuk N = 1,000,000 sampel: Membutuhkan 1 triliun operasi (mustahil untuk audio/video real-time).

📌 Fast Fourier Transform (FFT): O(N log2 N)

  • Ditemukan oleh Cooley dan Tukey (1965) menggunakan strategi Divide-and-Conquer.
  • Memanfaatkan simetri W_N^(k + N/2) = -W_N^k dan periodisitas Twiddle Factor W_N^(k+N) = W_N^k.
  • Total Perkalian Kompleks: (N / 2) log2(N).
  • Untuk N = 1024 sampel: Hanya membutuhkan ~5,120 perkalian kompleks (Lebih cepat 200x lipat!).

📌 Dampak pada Revolusi Digital

  • Penurunan eksponensial dari O(N^2) ke O(N log N) memungkinkan komputasi spektrum real-time pada mikroprosesor murah.
  • Menjadikan modem DSL, transmisi WiFi 802.11, dan pemrosesan audio digital terjangkau secara massal.

Arsitektur Algoritma FFT Radix-2 Decimation-in-Time (DIT)

Slide 5 / 14

Dekomposisi Sampel Genap dan Ganjil

$$X[k] = \sum_{r=0}^{N/2-1} x[2r] W_{N/2}^{kr} + W_N^k \sum_{r=0}^{N/2-1} x[2r+1] W_{N/2}^{kr} = E[k] + W_N^k \cdot O[k]$$

📐 Keterangan Variabel & Makna Fisik

  • E[k]: DFT N/2-titik dari sampel-sampel berindeks genap (even samples: x[0], x[2], x[4], ...).
  • O[k]: DFT N/2-titik dari sampel-sampel berindeks ganjil (odd samples: x[1], x[3], x[5], ...).
  • W_N^k: Twiddle factor pengali jalur cabang ganjil.
  • Butterfly Structure: Unit dasar komputasi FFT di mana sepasang nilai input dikombinasikan untuk menghasilkan sepasang output dengan satu perkalian kompleks.

🔢 Contoh Perhitungan Bertahap

  • Mekanisme Butterfly Computation:
  • Cabang Atas (k): X[k] = E[k] + W_N^k O[k].
  • Cabang Bawah (k + N/2): X[k + N/2] = E[k] - W_N^k O[k] (karena W_N^(k + N/2) = -W_N^k).
  • Satu perkalian kompleks W_N^k O[k] digunakan sekaligus untuk menghitung DUA nilai keluaran!
  • Bit-Reversal Sorting: Pengurutan data input diatur berdasarkan pembalikan urutan representasi biner indeks (misal 001_2 = 1 menjadi 100_2 = 4).

Fenomena Spectral Leakage: Mengapa Terjadi Kebocoran Spektrum?

Slide 6 / 14

📘 Akar Masalah Kebocoran Spektrum

  • DFT mengasumsikan secara implisit bahwa rekaman data berdurasi N sampel tersebut diulang-ulang secara periodik tak hingga seumur hidup.
  • Kondisi Ideal (Coherent Sampling): Jika durasi pengamatan memuat tepat kelipatan bulat dari periode sinyal, ujung awal dan ujung akhir sinyal menyatu mulus (tanpa diskontinuitas). Spektrum berupa satu garis jarum tunggal murni.
  • Kondisi Non-Koheren: Jika durasi pengamatan memotong sinyal di tengah gelombang, penyambungan periodik menimbulkan patahan tajam (diskontinuitas garis vertikal).
  • Diskontinuitas tajam tersebut menyebarkan energi ke seluruh bin frekuensi tetangga. Inilah Spectral Leakage!

🚀 Dampak Merugikan Spectral Leakage

  • Menyamarkan Nada Lemah: Sinyal frekuensi lemah yang berada di dekat sinyal kuat akan tertelan oleh side lobe kebocoran dari sinyal kuat.
  • Ketidaktepatan Estimasi Amplitudo: Nilai puncak spektrum turun karena energinya bocor menyebar ke bin lain.
  • Ketidakakuratan Pengukuran Harmonisa: Total Harmonic Distortion (THD) terukur lebih buruk dari kondisi aslinya.

Solusi Leakage: Fungsi Windowing & Karakteristik Trade-Off

Slide 7 / 14

📌 Rectangular (Kotak / Default)

  • w[n] = 1. Memotong data secara mendadak.
  • Lebar Main Lobe Paling Sempit (4 pi / N): Memberikan resolusi frekuensi paling tajam.
  • Atenuasi Side Lobe Sangat Buruk (-13 dB): Kebocoran spektral sangat parah.
  • Hanya cocok jika sinyal tepat periodik integer terhadap panjang window.

📌 Hann & Hamming (Klasik)

  • Hann: w[n] = 0.5 - 0.5 cos(2 pi n / (N-1)). Atenuasi side lobe -31 dB.
  • Hamming: w[n] = 0.54 - 0.46 cos(2 pi n / (N-1)). Atenuasi side lobe -41 dB.
  • Menghaluskan ujung data mendekati nol, meredam diskontinuitas secara signifikan.
  • Standar industri pemrosesan audio & speech.

📌 Blackman & Flat-Top

  • Blackman: Menambahkan harmonisa kedua, atenuasi side lobe spektakuler -58 dB. Main lobe melebar menjadi 12 pi / N.
  • Flat-Top: Puncak main lobe datar, digunakan khusus untuk kalibrasi instrumen pengukuran amplitudo tegangan yang sangat presisi.

Zero-Padding pada DFT: Mitos vs Fakta Ilmiah

Slide 8 / 14

📘 Apa itu Zero-Padding?

  • Zero-padding adalah teknik menambahkan deretan angka nol di ujung akhir sekuens sinyal sebelum menghitung FFT (misal sinyal 100 sampel ditambah 924 nol menjadi N = 1024).
  • Apakah Zero-Padding Menaikkan Resolusi Frekuensi Riil?
  • JAWABAN TEGAS: TIDAK! Resolusi fisik tetap ditentukan oleh panjang data asli (T_record). Dua puncak nada yang berdekatan dan sudah melebur tidak akan pernah bisa dipisahkan hanya dengan menambah angka nol!

🚀 Manfaat Riil Zero-Padding

  • 1. Interpolasi Spektral (High-Density Spectrum): Menghasilkan titik evaluasi kurva DTFT yang lebih rapat, sehingga bentuk puncak spektrum terlihat mulus dan nilai puncak lebih akurat.
  • 2. Efisiensi Algoritma FFT: Melengkapi panjang sinyal ganjil sembarang (misal 783 sampel) menjadi bilangan pangkat dua terdekat (N = 1024) agar dapat diproses oleh algoritma FFT Radix-2 yang sangat cepat.

Implementasi Python: Analisis Spektrum dengan FFT & Windowing

Slide 9 / 14

📖 Kaidah Perhitungan Spektrum dengan NumPy FFT

  • Gunakan np.fft.fft(x) untuk menghitung koefisien DFT.
  • Kalikan sinyal dengan window (misal np.hanning(N)) sebelum melakukan FFT.
  • Normalisasikan amplitudo dengan membagi N (atau jumlahan bobot window).
  • Ambil separuh spektrum positif (0 s.d. Fs/2) dan kalikan 2 untuk mengkompensasi energi spektrum negatif.
  • Sumbu frekuensi fisik dihitung dengan np.fft.fftfreq(N, 1/Fs).
Python Implementation (NumPy / SciPy) 
import numpy as np
import matplotlib.pyplot as plt

# Pembangkitan Dua Nada Berdekatan
Fs = 1000.0        # Frekuensi sampling = 1000 Hz
Duration = 0.5     # Durasi = 0.5 s (N = 500 sampel)
t = np.linspace(0, Duration, int(Fs * Duration), endpoint=False)
x = np.sin(2 * np.pi * 120 * t) + 0.3 * np.sin(2 * np.pi * 135 * t)

N = len(x)
# Terapkan Window Hann
window = np.hanning(N)
x_windowed = x * window

# Hitung FFT
X_fft = np.fft.fft(x_windowed)
freqs = np.fft.fftfreq(N, 1/Fs)

# Ambil Spektrum Satu Sisi Positif
pos_mask = freqs >= 0
f_pos = freqs[pos_mask]
mag = np.abs(X_fft[pos_mask]) * (2.0 / np.sum(window))

plt.figure(figsize=(9, 4))
plt.plot(f_pos, mag, 'b-', lw=1.5)
plt.title('Spektrum FFT Satu Sisi (Nada 120 Hz & 135 Hz)'); plt.xlabel('Frekuensi (Hz)')
plt.ylabel('Amplitudo Linear'); plt.xlim([50, 200]); plt.grid(True, alpha=0.5)
plt.show()

Tindak Lanjut & Referensi Perkuliahan

Slide 14 / 14

📋 Rangkuman Inti Pertemuan 10

  • DFT mendiskritisasi domain waktu dan frekuensi: X[k] = sum x[n] W_N^(kn).
  • Resolusi frekuensi Delta f = Fs / N ditentukan oleh durasi rekaman.
  • FFT memangkas kompleksitas komputasi dari O(N^2) menjadi O(N log N).
  • Windowing (Hann, Hamming, Blackman) mengatasi kebocoran spektral (spectral leakage).
  • Zero-padding memperhalus kurva tampilan spektrum, bukan menambah resolusi riil.
