Konvolusi Diskrit: Jantung Komputasi Pemfilteran Digital

Slide 2 / 14

📘 Makna Konseptual Konvolusi Diskrit

  • Konvolusi adalah mekanisme matematis fundamental di mana setiap sampel sinyal masukan x[k] menghasilkan replika respons impuls h[n-k] yang diskalakan oleh nilai amplitudo masukan tersebut.
  • Output akhir y[n] adalah hasil jumlahan superposisi dari seluruh salinan respons impuls terboboti tersebut seiring berjalannya waktu.
  • Konvolusi bukan sekadar perkalian, melainkan proses 'pencampuran dinamis' (blending/filtering) antara sinyal dengan karakteristik sistem.

🚀 Aplikasi Spektakuler Konvolusi di Industri

  • Convolution Reverb Audio: Merekam respons impuls akustik Katedral Kuno atau Gedung Opera Sydney, lalu mengkonvolusikannya dengan rekaman vokal kering di studio untuk menghasilkan gema akustik autentik!
  • Denoising & Smoothing Sinyal: Mengkonvolusikan sinyal sensor IoT dengan window moving average untuk meredam noise fluktuasi tajam.
  • Convolutional Neural Networks (CNN): Operasi konvolusi 2D diskrit menjadi blok bangunan utama kecerdasan buatan visi komputer modern.

Empat Langkah Metode Konvolusi Grafis

Slide 3 / 14

📌 1. Folding (Pencerminan)

  • Ubah variabel independen menjadi indeks dummy k.
  • Gambarkan x[k] dan h[k].
  • Cerminkan respons impuls terhadap sumbu origin k = 0 untuk membentuk sekuens h[-k].

📌 2. Shifting (Pergeseran)

  • Geser sekuens h[-k] sejauh n sampel ke kanan (jika n > 0) atau ke kiri (jika n < 0) untuk menghasilkan h[n - k].
  • Variabel n menentukan titik waktu evaluasi output y[n].

📌 3. Multiplication & Summation

  • Perkalian: Kalikan sinyal x[k] dengan sinyal tergeser h[n - k] pada setiap titik k yang saling bertumpuk (overlap).
  • Penjumlahan: Jumlahkan seluruh hasil kali tersebut untuk memperoleh satu nilai skalar output: y[n] = sum x[k] h[n-k].

Metode Tabular & Matriks Toeplitz untuk Perhitungan Cepat

Slide 4 / 14

Representasi Perkalian Matriks Konvolusi Diskrit

$$\mathbf{y} = \mathbf{H} \cdot \mathbf{x} \quad \iff \quad \begin{bmatrix} y[0] \\ y[1] \\ y[2] \\ \vdots \\ y[L_y-1] \end{bmatrix} = \begin{bmatrix} h[0] & 0 & 0 \\ h[1] & h[0] & 0 \\ h[2] & h[1] & h[0] \\ \vdots & \ddots & \vdots \\ 0 & \dots & h[L_h-1] \end{bmatrix} \begin{bmatrix} x[0] \\ x[1] \\ x[2] \end{bmatrix}$$

📐 Keterangan Variabel & Makna Fisik

  • Lx: Panjang jumlah sampel sinyal input x[n].
  • Lh: Panjang jumlah sampel respons impuls h[n].
  • Ly: Panjang sekuens hasil konvolusi: Ly = Lx + Lh - 1.
  • Rentang Waktu Output: Jika x[n] dimulai pada n_x_start dan h[n] pada n_h_start, maka output y[n] dimulai tepat pada n_y_start = n_x_start + n_h_start.
  • Matriks Toeplitz H: Matriks khusus di mana elemen pada setiap diagonal menurun bernilai konstan.

🔢 Contoh Perhitungan Bertahap

  • Contoh: x[n] = { [1], 2, 3 } (Lx = 3) dan h[n] = { [2], 1 } (Lh = 2).
  • Hitung panjang output: Ly = 3 + 2 - 1 = 4 sampel.
  • Metode Tabular Grid (Tabel Perkalian Silang):
  • Baris x[k] dikalikan kolom h[n]:
  • Baris 0 (h[0]=2): 2*1=2, 2*2=4, 2*3=6.
  • Baris 1 (h[1]=1): 1*1=1, 1*2=2, 1*3=3 (bergeser satu kolom).
  • Jumlahkan diagonal miring: y[0] = 2; y[1] = 4+1 = 5; y[2] = 6+2 = 8; y[3] = 3.
  • Hasil Konvolusi: y[n] = { [2], 5, 8, 3 }.

Sifat-Sifat Aljabar Konvolusi Diskrit

Slide 5 / 14

📌 1. Sifat Komutatif (Pertukaran)

  • x[n] * h[n] = h[n] * x[n].
  • Secara fisik: Melewatkan sinyal x melalui filter h memberikan hasil yang sama persis dengan melewatkan sinyal h melalui filter x.
  • Sangat memudahkan perhitungan analitis (pilih sekuens yang lebih pendek untuk dilipat/digeser).

📌 2. Sifat Asosiatif (Pengelompokan)

  • (x[n] * h1[n]) * h2[n] = x[n] * (h1[n] * h2[n]).
  • Sistem Kaskade (Seri): Dua filter yang dihubungkan secara seri dapat digabungkan menjadi satu filter ekuivalen tunggal: h_eq[n] = h1[n] * h2[n].

📌 3. Sifat Distributif

  • x[n] * (h1[n] + h2[n]) = (x[n] * h1[n]) + (x[n] * h2[n]).
  • Sistem Paralel: Dua filter yang dihubungkan secara paralel dapat dijumlahkan respons impulsnya: h_eq[n] = h1[n] + h2[n].

Analisis Korelasi Sinyal: Cross-Correlation & Auto-Correlation

Slide 6 / 14

Formulasi Matematis Korelasi Diskrit

$$r_{xy}[l] = \sum_{n=-\infty}^{\infty} x[n] y[n - l] \qquad r_{xx}[l] = \sum_{n=-\infty}^{\infty} x[n] x[n - l]$$

📐 Keterangan Variabel & Makna Fisik

  • r_xy[l]: Cross-correlation antara dua sinyal x[n] dan y[n] pada lag pergeseran l.
  • r_xx[l]: Auto-correlation dari sinyal x[n] dengan dirinya sendiri yang digeser sejauh l sampel.
  • l (Lag): Parameter pergeseran waktu bilangan bulat.
  • Perbedaan Mutlak dengan Konvolusi: Pada korelasi TIDAK ADA operasi pencerminan/folding (tidak ada tanda minus pada variabel dummy).
  • Hubungan dengan Konvolusi: r_xy[l] = x[l] * y[-l].

🔢 Contoh Perhitungan Bertahap

  • Aplikasi Cross-Correlation: Pengukuran Kemiripan & Estimasi Keterlambatan Waktu (Time-of-Flight / Delay Estimation).
  • Contoh Radar / Sonar: Pancarkan pulsa x[n]. Tangkap pantulan gema y[n] = alpha * x[n - D] + noise.
  • Hitung r_xy[l]: Titik puncak tertinggi (peak) dari kurva r_xy[l] terjadi tepat pada nilai lag l = D!
  • Dengan mengalikan D dengan periode sampling Ts dan kecepatan rambat gelombang, jarak objek target dapat dihitung dengan presisi milimeter!

Auto-Correlation & Teorema Wiener-Khinchin

Slide 7 / 14

📘 Sifat Unik Auto-Correlation r_xx[l]

  • Nilai Maksimum Selalu di Origin (l = 0): Nilai r_xx[0] merepresentasikan Total Energi Sinyal (r_xx[0] = sum |x[n]|^2 = E).
  • Kaidah Batas Atas: |r_xx[l]| <= r_xx[0] untuk seluruh lag l != 0.
  • Simetri Genap: r_xx[-l] = r_xx[l] (untuk sinyal real).
  • Deteksi Periodisitas Tersembunyi: Jika sinyal tertutup noise sangat lebat sehingga bentuk gelombangnya tidak terlihat, auto-correlation akan memunculkan puncak berulang periodik pada interval lag kelipatan periode dasar N0!

🚀 Teorema Wiener-Khinchin

  • Salah satu teorema paling agung dalam teori probabilitas dan pengolahan sinyal digital:
  • Transformasi Fourier dari fungsi auto-correlation sebuah sinyal adalah sama persis dengan Power Spectral Density (PSD) dari sinyal tersebut:
  • FT{ r_xx[l] } = S_xx(e^(j omega)) = |X(e^(j omega))|^2.
  • Fondasi utama analisis spektrum daya pada radar, astronomi radio, dan analisis getaran mesin industri.

Perbedaan Ringkas: Konvolusi vs Korelasi

Slide 8 / 14

📘 Operasi Konvolusi Diskrit (x * h)

  • Tujuan Utama: Pemfilteran (Filtering) dan pemodelan transformasi sistem LTI.
  • Operasi Waktu: Ada pencerminan sumbu (folding) sinyal kedua sebelum digeser: h[n - k].
  • Sifat Komutatif: Ya, berlaku mutlak (x * h = h * x).
  • Domain Transformasi: Berkorespondensi dengan perkalian spektrum frekuensi: Y(w) = X(w) * H(w).

🚀 Operasi Korelasi Diskrit (r_xy)

  • Tujuan Utama: Mengukur derajat kemiripan sinyal, deteksi pola (pattern matching), dan estimasi time delay.
  • Operasi Waktu: Tanpa pencerminan sumbu (direct shifting): y[n - l].
  • Sifat Komutatif: Tidak komutatif secara langsung (r_xy[l] = r_yx[-l]).
  • Domain Transformasi: Berkorespondensi dengan perkalian spektrum dengan konjugat kompleksnya: S_xy(w) = X(w) * Y*(w).

Implementasi Python: Konvolusi Manual vs NumPy

Slide 9 / 14

📖 Algoritma Konvolusi Diskrit O(N*M)

  • Memahami algoritma konvolusi dari loop tingkat dasar (scratch implementation) memperdalam pemahaman mengenai pergeseran indeks.
  • Fungsi np.convolve(x, h, mode='full') dioptimasi dalam bahasa C untuk eksekusi vektor berkecepatan tinggi.
  • Panjang output selalu sama dengan len(x) + len(h) - 1.
Python Implementation (NumPy / SciPy) 
import numpy as np

def discrete_convolution_scratch(x, h):
    Lx, Lh = len(x), len(h)
    Ly = Lx + Lh - 1
    y = np.zeros(Ly)
    
    # Implementasi loop ganda sesuai formula matematis
    for n in range(Ly):
        for k in range(Lx):
            if 0 <= (n - k) < Lh:
                y[n] += x[k] * h[n - k]
    return y

# Uji Coba Sekuens Uji
x_sig = np.array([1.0, 2.0, 3.0, 1.0])
h_imp = np.array([1.0, -1.0, 2.0])

y_manual = discrete_convolution_scratch(x_sig, h_imp)
y_numpy = np.convolve(x_sig, h_imp, mode='full')

print('Hasil Konvolusi Manual :', y_manual)
print('Hasil NumPy Convolve   :', y_numpy)
print('Apakah Hasil Identik?  :', np.allclose(y_manual, y_numpy))

Integrasi AI: Debugging Logika Boundary Indexing

Slide 11 / 14

📘 Pemanfaatan AI untuk Optimasi Komputasi

  • Prompt AI: 'Bagaimana cara mengubah algoritma loop konvolusi diskrit O(N^2) menjadi komputasi berbasis FFT O(N log N) menggunakan metode Overlap-Add pada Python?'
  • Boundary Debugging: 'Script korelasi saya menghasilkan indeks lag negatif yang bergeser. Bagaimana cara membuat array sumbu lag yang simetris dari -(N-1) hingga +(N-1)?'

🚀 Kewajiban Validasi Mahasiswa

  • Verifikasi Padding FFT: Jika menggunakan FFT untuk konvolusi, ukuran FFT wajib minimal N1 + N2 - 1 untuk mencegah circular convolution aliasing.
  • Pemeriksaan Zero-Lag Alignment: Pastikan titik tengah array korelasi tepat berkorespondensi dengan lag l = 0.
