Urgensi DSP di Era Artificial Intelligence & Komputasi Modern

Slide 3 / 14

📘 Mengapa Pengolahan Sinyal Digital Mutlak Diperlukan?

  • Dunia Fisik Bersifat Analog: Suara ucapan manusia, denyut jantung (EKG), gelombang seismik bumi, dan transmisi radio adalah fenomena kontinu waktu.
  • Komputer Bekerja dalam Domain Biner Diskrit: Algoritma cerdas, LLM, dan model visi komputer tidak dapat memproses gelombang fisik kontinu secara langsung.
  • DSP sebagai 'Mata dan Telinga' AI: Tanpa ekstraksi fitur DSP (filtering, denoising, transformasi Fourier, spektrogram), model AI akan tenggelam dalam derau (noise) mentah.
  • Efisiensi Energi & Real-Time Processing: DSP modern dirancang untuk dieksekusi secara instan pada chip mikroprosesor berdaya rendah (Edge AI / IoT).

🚀 Dampak Disrupsi Teknologi Berbasis DSP

  • Active Noise Cancellation (ANC): Memproduksi 'anti-noise' dalam hitungan mikrodetik untuk meredam kebisingan kabin pesawat dan headphone.
  • Sistem Biomedis Modern: Menghilangkan artefak interferensi jala-jala listrik 50 Hz pada rekaman elektrokardiogram pasien kritis.
  • Komunikasi Seluler 5G/6G & WiFi 7: Modulasi OFDM canggih yang mengalirkan data gigabit per detik melalui udara.
  • Smart Audio & Asisten Suara: Voice Activity Detection (VAD) dan Beamforming mikrofon array pada perangkat pintar.

Taksonomi & Klasifikasi Sinyal: Kontinu, Diskrit, dan Digital

Slide 4 / 14

📌 Sinyal Waktu Kontinu x(t)

  • Didefinisikan untuk setiap nilai kontinu waktu t dalam bilangan real (t in R).
  • Amplitudo x(t) bernilai kontinu dalam rentang dinamis tertentu.
  • Contoh: Tegangan keluaran mikrofon analog, tekanan akustik udara, suhu ruangan kontinu.

📌 Sinyal Waktu Diskrit x[n]

  • Didefinisikan hanya pada indeks bilangan bulat diskrit (n in Z).
  • Waktu telah disampling dengan periode Ts, di mana t = n * Ts.
  • Amplitudo masih bernilai kontinu (presisi tak hingga sebelum kuantisasi register).

📌 Sinyal Digital x_d[n]

  • Sumbu waktu terdiskritisasi (disampling) dan sumbu amplitudo terkuantisasi.
  • Nilai amplitudo dibatasi ke dalam level diskrit berhingga (kata biner b-bit).
  • Representasi riil yang tersimpan di memori komputer, flash RAM, atau file WAV/MP3.

Formulasi Matematis Sinyal Sinusoidal Kontinu vs Diskrit

Slide 5 / 14

Representasi Sinyal Sinusoidal Domain Waktu

$$x(t) = A \cos(2\pi F t + \theta) \quad \longleftrightarrow \quad x[n] = A \cos(\omega n + \theta) = A \cos\left(2\pi \frac{F}{F_s} n + \theta\right)$$

📐 Keterangan Variabel & Makna Fisik

  • A: Amplitudo puncak sinyal (mengukur kekuatan atau simpangan maksimum).
  • F: Frekuensi siklik analog dalam satuan Hertz (siklus per detik).
  • t: Waktu fisik kontinu dalam detik (sekon).
  • Fs: Frekuensi sampling (laju pencuplikan per detik, Fs = 1/Ts).
  • omega: Frekuensi sudut ternormalisasi diskrit (radian/sampel), omega = 2*pi*(F/Fs).
  • theta: Pergeseran sudut fase awal (radian).

🔢 Contoh Perhitungan Bertahap

  • Langkah 1: Tentukan sinyal analog x(t) = 5 cos(200*pi*t). Frekuensi analog F = 100 Hz.
  • Langkah 2: Pilih frekuensi sampling Fs = 800 Hz (memenuhi syarat Nyquist Fs > 2F).
  • Langkah 3: Substitusikan waktu kontinu t = n / Fs = n / 800 ke dalam sinyal.
  • Langkah 4: Hitung frekuensi ternormalisasi: omega = 200*pi / 800 = pi/4 rad/sampel.
  • Langkah 5: Diperoleh sekuens diskrit: x[n] = 5 cos((pi/4)*n). Periode dasar N = 2*pi / (pi/4) = 8 sampel.

Arsitektur Blok Diagram Sistem DSP End-to-End

Slide 6 / 14

📌 1. Tahap Input Analog

  • Transduser (Sensor/Mikrofon): Mengubah besaran fisik ke tegangan listrik.
  • Anti-Aliasing Filter (LPF Analog): Memangkas frekuensi di atas Fs/2 guna mencegah distorsi aliasing sebelum proses pencuplikan.

📌 2. Inti Konversi & Prosesor DSP

  • ADC (Analog-to-Digital Converter): Sample-and-Hold & Kuantisasi biner b-bit.
  • DSP Core (CPU / GPU / FPGA / NPU): Menjalankan algoritma pemfilteran FIR/IIR, FFT, dan transformasi secara matematis presisi.

📌 3. Tahap Rekonstruksi Output

  • DAC (Digital-to-Analog Converter): Mengubah sekuens digital kembali ke tegangan bertangga.
  • Reconstruction Smoothing Filter: Menghilangkan komponen frekuensi harmonisa pencuplikan untuk menghasilkan sinyal analog mulus.

Komparasi Keunggulan: Sistem Pemrosesan Digital vs Analog

Slide 7 / 14

📘 Keunggulan Mutlak Sistem Digital (DSP)

  • Presisi & Keterulangan (Reproducibility): Tidak terpengaruh toleransi nilai resistor/kapasitor maupun perubahan suhu lingkungan (thermal drift).
  • Fleksibilitas Pemrograman: Mengubah frekuensi cutoff filter semudah mengubah koefisien angka di baris kode, tanpa mengganti hardware fisik.
  • Kemampuan Implementasi Kompleksitas Tinggi: Mampu merealisasikan filter fase linier sempurna (FIR) yang mustahil dibuat dengan rangkaian analog pasif/aktif.
  • Kemudahan Kompresi & Penyimpanan: Data terkuantisasi dapat dikompresi (FLAC, MP3, AAC) dan ditransmisikan tanpa akumulasi noise kabel.

🚀 Tantangan & Batasan Sistem Digital

  • Konsumsi Daya & Kecepatan ADC: Sinyal ultra-tinggi (misalnya sinyal radar frekuensi gelombang mikro puluh GHz) menuntut ADC berdaya besar dan mahal.
  • Noise Kuantisasi: Pembulatan ke dalam representasi bit berhingga menimbulkan derau dasar (quantization error floor).
  • Latensi Pemrosesan (Algorithmic Latency): Waktu buffering dan komputasi FFT/filter menimbulkan delay yang harus dioptimasi pada aplikasi real-time kritis.

Ekosistem Komputasi DSP Berbasis Python

Slide 8 / 14

📌 NumPy (Numerical Python)

  • Tulang punggung representasi larik vektor (ndarray) berkecepatan C.
  • Operasi elemen-ke-elemen, dot product, matriks, dan aljabar linear sekuens sinyal diskrit.
  • Contoh fungsi: np.arange, np.linspace, np.sin, np.convolve.

📌 SciPy (Signal Processing)

  • Modul scipy.signal menyediakan algoritma DSP kelas industri.
  • Desain filter FIR/IIR (firwin, butter, cheby1), respons frekuensi (freqz), transformasi Fourier, dan konvolusi cepat.
  • Fungsi: scipy.signal.lfilter, sosfilt, spectrogram.

📌 Matplotlib & Visualisasi

  • Visualisasi grafik teknik standar publikasi ilmiah IEEE.
  • Fungsi stem() khusus untuk merepresentasikan sekuens diskrit impuls jarum.
  • Plotting domain frekuensi, kurva magnitudo (dB), fase, dan diagram pole-zero.

Implementasi Python: Visualisasi Sinyal Kontinu vs Sinyal Diskrit

Slide 9 / 14

📖 Kaidah Visualisasi Sinyal Diskrit

  • Sinyal analog didekati menggunakan grid waktu sangat rapat (oversampling, misalnya dt = 0.0001 s) dengan fungsi plt.plot().
  • Sinyal diskrit wajib divisualisasikan menggunakan diagram jarum impuls dengan fungsi plt.stem(), karena sinyal hanya terdefinisi pada indeks bilangan bulat n.
  • Perhatikan parameter use_line_collection=True pada matplotlib untuk performa rendering grafis yang optimal.
Python Implementation (NumPy / SciPy) 
import numpy as np
import matplotlib.pyplot as plt

# 1. Parameter Sinyal
F_signal = 5.0     # Frekuensi analog = 5 Hz
Fs = 40.0          # Frekuensi sampling = 40 Hz
Duration = 1.0     # Durasi pengamatan = 1 detik

# 2. Pendekatan Analog vs Diskrit
t_analog = np.linspace(0, Duration, 1000)
x_analog = np.sin(2 * np.pi * F_signal * t_analog)

n_indices = np.arange(0, int(Fs * Duration))
t_discrete = n_indices / Fs
x_discrete = np.sin(2 * np.pi * F_signal * t_discrete)

# 3. Plotting Berdampingan
plt.figure(figsize=(10, 4))
plt.plot(t_analog, x_analog, 'lightgray', label='Analog x(t)')
plt.stem(t_discrete, x_discrete, linefmt='b-', markerfmt='bo', basefmt='r-', label='Diskrit x[n]')
plt.title('Representasi Sinyal Kontinu vs Sinyal Diskrit (Fs = 40 Hz)')
plt.xlabel('Waktu (detik)'); plt.ylabel('Amplitudo')
plt.grid(True, linestyle='--', alpha=0.6); plt.legend()
plt.show()
