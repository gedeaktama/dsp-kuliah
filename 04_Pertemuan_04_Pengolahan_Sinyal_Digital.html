Konsep Sistem Waktu Diskrit: Operator Transformasi

Slide 2 / 15

📘 Definisi Formal Sistem Diskrit

  • Sistem waktu diskrit adalah sebuah operator matematik atau piranti komputasi T[ . ] yang memetakan sinyal masukan (input sequence) x[n] menjadi sinyal keluaran (output sequence) y[n].
  • Notasi Operator: y[n] = T{ x[n] }.
  • Sistem dapat berupa rangkaian keras elektronik (ASIC, FPGA, DSP processor) atau algoritma baris kode perangkat lunak (Python, C++).

🚀 Mengapa Pengujian Sifat Sistem Sangat Krusial?

  • Sebelum mendesain filter, melakukan analisis spektrum, atau merancang kendali cerdas, kita wajib mengetahui watak dasar sistem yang dihadapi.
  • Jika sistem terbukti Linear dan Time-Invariant (LTI), kita dapat memanfaatkan matematika konvolusi dan Transformasi Fourier/Z yang sangat kuat.
  • Jika sistem terbukti non-linear atau time-varying, metode LTI standar tidak dapat diterapkan secara langsung dan memerlukan pendekatan khusus.

Sifat 1: Linearitas (Linearity & Superposition)

Slide 3 / 15

Prinsip Superposisi (Homogenitas & Aditivitas)

$$\mathcal{T}\big(a x_1[n] + b x_2[n]\big) = a \mathcal{T}\big(x_1[n]\big) + b \mathcal{T}\big(x_2[n]\big) = a y_1[n] + b y_2[n]$$

📐 Keterangan Variabel & Makna Fisik

  • T[ . ]: Operator transformasi sistem.
  • x1[n], x2[n]: Dua sinyal masukan sembarang.
  • y1[n], y2[n]: Respons output masing-masing terhadap masukan x1[n] dan x2[n].
  • a, b: Konstanta skalar pengali sembarang (dapat berupa bilangan real atau kompleks).
  • Aditivitas: Respons terhadap jumlahan input sama dengan jumlahan respons individual.
  • Homogenitas (Penskalaan): Penskalaan input menghasilkan penskalaan proporsional pada output.

🔢 Contoh Perhitungan Bertahap

  • Uji Cepat Non-Linearitas (Zero-Input Zero-Output Rule):
  • Jika input x[n] = 0 menghasilkan output y[n] != 0, maka sistem tersebut DIPASTIKAN NON-LINEAR!
  • Contoh: y[n] = 2 x[n] + 3. Jika x[n] = 0, y[n] = 3 != 0. Sistem ini non-linear (affine system).
  • Contoh Linear: y[n] = n * x[n]. Uji: T{a x1[n] + b x2[n]} = n(a x1[n] + b x2[n]) = a(n x1[n]) + b(n x2[n]) = a y1[n] + b y2[n]. Terbukti linear murni!

Contoh Uji Analitis: Sistem Linear vs Non-Linear

Slide 4 / 15

📘 Kasus A: y[n] = (x[n])^2 (Sistem Kuadrat)

  • Langkah 1: Bentuk kombinasi linier input: x3[n] = a x1[n] + b x2[n].
  • Langkah 2: Hitung respons y3[n] = T{x3[n]} = (a x1[n] + b x2[n])^2.
  • Ekspansi: y3[n] = a^2 (x1[n])^2 + b^2 (x2[n])^2 + 2 a b x1[n] x2[n].
  • Langkah 3: Bandingkan dengan kombinasi output: a y1[n] + b y2[n] = a (x1[n])^2 + b (x2[n])^2.
  • Kesimpulan: Karena y3[n] != a y1[n] + b y2[n] (muncul suku silang 2ab x1 x2), maka SISTEM TIDAK LINEAR (NON-LINEAR)!

🚀 Kasus B: y[n] = x[n - 1] - 0.5 x[n - 2]

  • Langkah 1: Input x3[n] = a x1[n] + b x2[n].
  • Langkah 2: y3[n] = (a x1[n-1] + b x2[n-1]) - 0.5 (a x1[n-2] + b x2[n-2]).
  • Langkah 3: Kelompokkan konstanta a dan b:
  • y3[n] = a [x1[n-1] - 0.5 x1[n-2]] + b [x2[n-1] - 0.5 x2[n-2]].
  • Perhatikan bahwa bagian dalam kurung siku adalah tepat y1[n] dan y2[n]!
  • Kesimpulan: y3[n] = a y1[n] + b y2[n]. SISTEM TERBUKTI LINEAR!

Sifat 2: Time-Invariance (Invarian Waktu)

Slide 5 / 15

Syarat Mutlak Sistem Invarian Waktu

$$x_1[n] = x[n - k] \implies y_1[n] = \mathcal{T}\big(x[n - k]\big) = y[n - k] \quad \text{untuk setiap } k \in \mathbb{Z}$$

📐 Keterangan Variabel & Makna Fisik

  • k: Nilai pergeseran waktu bilangan bulat sembarang.
  • y[n - k]: Respons output asli yang digeser sejauh k sampel.
  • T{ x[n - k] }: Respons output baru ketika sistem diberi masukan yang telah digeser.
  • Prinsip Fisik: Karakteristik dan parameter sistem tidak berubah seiring berjalannya waktu kalender. Eksperimen hari ini memberikan hasil yang sama persis dengan eksperimen besok.

🔢 Contoh Perhitungan Bertahap

  • Kaidah Deteksi Cepat Sistem Time-Varying:
  • 1. Koefisien Eksplisit n: Jika persamaan memiliki koefisien pengali yang bergantung langsung pada variabel n (misal y[n] = n x[n] atau y[n] = cos(0.2 pi n) x[n]), sistem DIPASTIKAN TIME-VARYING!
  • 2. Transformasi Sumbu Waktu pada Input: Jika input mengalami scaling waktu atau pembalikan (misal y[n] = x[2n] atau y[n] = x[-n]), sistem DIPASTIKAN TIME-VARYING!
  • 3. Jika seluruh koefisien konstan dan indeks waktu hanya berupa pergeseran murni (misal y[n] = 3 x[n-1] + 2 x[n-4]), sistem TERBUKTI TIME-INVARIANT!

Contoh Uji Analitis: Time-Invariant vs Time-Varying

Slide 6 / 15

📘 Kasus A: y[n] = x[2n] (Kompresor Waktu)

  • Langkah 1: Berikan input tergeser x1[n] = x[n - k].
  • Langkah 2: Respons baru y1[n] = T{x1[n]} = x1[2n] = x[2n - k]. (Hanya n yang diganti 2n).
  • Langkah 3: Geser output asli y[n] sejauh k sampel: y[n - k] = x[2(n - k)] = x[2n - 2k].
  • Langkah 4: Bandingkan y1[n] dengan y[n - k]:
  • x[2n - k] != x[2n - 2k].
  • Kesimpulan: y1[n] != y[n - k]. SISTEM ADALAH TIME-VARYING (TIDAK INVARIAN WAKTU)!

🚀 Kasus B: y[n] = 3 x[n] + x[n - 3]

  • Langkah 1: Input tergeser x1[n] = x[n - k].
  • Langkah 2: Respons baru y1[n] = 3 x1[n] + x1[n - 3] = 3 x[n - k] + x[n - k - 3].
  • Langkah 3: Geser output asli y[n] sejauh k sampel: y[n - k] = 3 x[n - k] + x[(n - k) - 3].
  • Langkah 4: Evaluasi kesamaan: y1[n] tepat sama dengan y[n - k] untuk seluruh nilai k.
  • Kesimpulan: SISTEM ADALAH TIME-INVARIANT (INVARIAN WAKTU)!

Sifat 3: Kausalitas (Causality)

Slide 7 / 15

📌 Definisi Kausalitas Fisik

  • Sistem disebut Kausal jika output pada waktu n saat ini y[n] HANYA bergantung pada nilai input saat ini x[n] dan input masa lalu (x[n-1], x[n-2], ...).
  • Sistem sama sekali tidak bergantung pada nilai input masa depan (x[n+1], x[n+2], ...).
  • Prinsip 'Tidak dapat meramal masa depan'.

📌 Implementasi Real-Time

  • Seluruh sistem pemrosesan sinyal real-time (live audio, radar aktif, kendali motor) WAJIB bersifat kausal.
  • Contoh Kausal: y[n] = 0.5 x[n] + 0.5 x[n-1] (Moving Average mundur).
  • Contoh Non-Kausal: y[n] = (x[n+1] + x[n] + x[n-1]) / 3 (Membutuhkan sampel masa depan x[n+1]).

📌 Aplikasi Non-Kausal Offline

  • Apakah sistem non-kausal berguna? Ya, sangat berguna dalam pemrosesan data offline!
  • Contoh: Pemrosesan rekaman audio yang sudah tersimpan di harddisk, restorasi foto digital, atau analisis data seismik historis.
  • Karena seluruh data sudah ada di memori, indeks n+1 dapat diakses bebas.

Sifat 4: Stabilitas BIBO (Bounded-Input Bounded-Output)

Slide 8 / 15

Kriteria Kestabilan BIBO Sistem Diskrit

$$|x[n]| \le M_x < \infty \quad \forall n \implies |y[n]| \le M_y < \infty \quad \forall n$$

📐 Keterangan Variabel & Makna Fisik

  • Mx: Batas atas positif berhingga dari amplitudo sinyal masukan.
  • My: Batas atas positif berhingga dari amplitudo sinyal keluaran yang dihasilkan.
  • BIBO Stable: Jika setiap input yang terbatas (tidak pernah meledak ke tak terhingga) dijamin menghasilkan output yang juga selalu terbatas.
  • Kondisi Unstable: Sistem yang output-nya dapat berosilasi tak hingga atau melonjak divergen ke tak terhingga meskipun input-nya sangat kecil.

🔢 Contoh Perhitungan Bertahap

  • Contoh Sistem Akumulator Tak Terbatas: y[n] = sum_{k=-inf}^{n} x[k].
  • Uji Stabilitas: Berikan input terbatas berupa unit step x[n] = u[n] (amplitudo |x[n]| <= 1, terbatas).
  • Hitung output untuk n >= 0: y[n] = sum_{k=0}^{n} 1 = n + 1.
  • Evaluasi Limit: Saat n -> inf, y[n] -> inf. Output menjadi tak terbatas (divergen)!
  • Kesimpulan: Sistem Akumulator murni TIDAK STABIL BIBO!

Sifat 5: Memori Sistem (Memoryless vs Dynamic)

Slide 9 / 15

📘 Sistem Tanpa Memori (Memoryless / Static)

  • Output pada waktu n saat ini HANYA bergantung pada input pada waktu n saat ini saja.
  • Sistem tidak memerlukan komponen register memori (unit delay element) untuk menyimpan data lama.
  • Bentuk Umum: y[n] = f( x[n] ).
  • Contoh: y[n] = 5 x[n], y[n] = (x[n])^3, y[n] = sign( x[n] ).

🚀 Sistem Dengan Memori (Dynamic)

  • Output saat ini bergantung pada nilai input di masa lalu atau masa depan.
  • Membutuhkan register flip-flop / buffer memori RAM untuk menyimpan sampel terdahulu.
  • Memori Berhingga (Finite Memory): Bergantung pada M sampel masa lalu (misal filter FIR).
  • Memori Tak Berhingga (Infinite Memory): Bergantung pada seluruh riwayat masa lalu melalui umpan balik output (misal filter IIR).

Implementasi Python: Framework Pengujian Sifat Sistem

Slide 10 / 15

📖 Pengujian Empiris Numerik Sifat Sistem

  • Meskipun pembuktian matematis bersifat formal, kita dapat membangun script pengujian empiris menggunakan sinyal acak (random signals) untuk mendeteksi pelanggaran sifat secara otomatis.
  • Jika ditemukan minimal satu pasang sinyal acak yang melanggar rumus superposisi, sistem terbukti 100% non-linear.
Python Implementation (NumPy / SciPy) 
import numpy as np

def test_system_linearity(system_func, tolerance=1e-6):
    # Pembangkitan dua sinyal acak
    n = np.arange(0, 50)
    x1 = np.random.randn(len(n))
    x2 = np.random.randn(len(n))
    a, b = 2.5, -1.8
    
    # Jalur 1: Superposisi input terlebih dahulu
    x_comb = a * x1 + b * x2
    y_from_comb = system_func(x_comb)
    
    # Jalur 2: Superposisi output individual
    y1 = system_func(x1)
    y2 = system_func(x2)
    y_superposed = a * y1 + b * y2
    
    # Evaluasi selisih maksimum
    max_err = np.max(np.abs(y_from_comb - y_superposed))
    is_linear = max_err < tolerance
    return is_linear, max_err

# Uji Coba Dua Sistem Berbeda
sys_linear = lambda x: 3.0 * x + np.roll(x, 1)
sys_nonlinear = lambda x: x**2

print('Sys Linear:', test_system_linearity(sys_linear))
print('Sys Non-Linear:', test_system_linearity(sys_nonlinear))
