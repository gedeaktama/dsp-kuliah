Tahap 1 & 2: Preprocessing Sinyal (Detrending & Normalisasi)

Slide 3 / 13

📌 DC-Offset Removal

  • Sinyal analog seringkali membawa pergeseran tegangan rata-rata bukan nol (mean != 0) yang memboroskan rentang dinamis ADC.
  • Metode Pengurangan Rata-Rata: x_clean[n] = x[n] - np.mean(x).
  • Metode Filter Notch DC: High-Pass Filter IIR orde-1 dengan pole sangat dekat ke z = 1 (misal H(z) = (1 - z^-1) / (1 - 0.995 z^-1)).

📌 Linear Detrending

  • Mengoreksi pergeseran garis dasar (baseline wander) akibat perubahan suhu sensor atau pernapasan pasien.
  • Mengestimasi tren linier menggunakan regresi kuadrat terkecil (least-squares line fitting) lalu menguranginya dari sinyal: scipy.signal.detrend(x).

📌 Normalisasi Amplitudo

  • Peak Normalization: Membagi seluruh sinyal dengan amplitudo maksimum mutlak: x_norm = x / np.max(np.abs(x)). Menjamin rentang ketat [-1.0, +1.0].
  • RMS Normalization (Z-Score Standard): Mengatur rata-rata = 0 dan variansi energi = 1, sangat krusial sebagai masukan model AI / Neural Network.

Tahap 3 & 4: Denoising, Framing & Windowing

Slide 4 / 13

📘 Filtering & Denoising Terpadu

  • Filtering Bertingkat: Kombinasi High-Pass (menghilangkan drift) + Low-Pass (menghilangkan noise frekuensi tinggi) + Notch Filter (menghilangkan interferensi listrik 50 Hz).
  • Median Filtering: Menggantikan setiap sampel dengan nilai median dari tetangga sekitarnya. Sangat efektif menghilangkan derau bintik impulsif (Salt-and-Pepper Noise / Spike Noise) tanpa mengaburkan tepi transisi sinyal yang tajam.

🚀 Framing & Overlapping Analysis

  • Sinyal nyata seperti suara bicara manusia (speech) bersifat Non-Stasioner (karakteristik frekuensinya berubah seiring waktu).
  • Prinsip Quasi-Stationary: Dalam selang waktu sangat pendek (10 s.d. 30 milidetik), sinyal suara dapat diasumsikan stasioner.
  • Framing: Memotong sinyal panjang menjadi potongan frame-frame berdurasi N_frame (misal 25 ms).
  • Overlap (Hop Size): Menggeser frame sebesar 50% panjang frame agar transisi informasi antar frame tidak terputus di perbatasan window.

Tahap 5: Ekstraksi Fitur Domain Waktu (Temporal Features)

Slide 5 / 13

📌 1. Zero-Crossing Rate (ZCR)

  • Menghitung berapa kali sinyal memotong sumbu nol (berubah polaritas dari positif ke negatif atau sebaliknya) dalam satu frame waktu.
  • Aplikasi: Membedakan antara suara berdesis tanpa getaran pita suara (Unvoiced Speech / Fricatives seperti 's', 'f', 't') yang memiliki ZCR sangat tinggi, dengan suara vokal (Voiced) yang ber-ZCR rendah.

📌 2. Short-Time Energy (STE)

  • STE = sum_{m=0}^{N-1} (x[m] * w[m])^2.
  • Mengukur kekuatan energi sesaat sinyal pada setiap frame waktu.
  • Aplikasi Utama: Voice Activity Detection (VAD) untuk mendeteksi kapan seseorang mulai berbicara dan kapan jeda hening (silence detection) pada asisten suara cerdas.

📌 3. Root Mean Square (RMS)

  • RMS = sqrt( (1/N) * sum x[m]^2 ).
  • Merepresentasikan intensitas kenyaringan (loudness) perseptual sinyal audio.
  • Digunakan untuk normalisasi dinamika sinyal pada sistem broadcast radio/podcast.

Tahap 5 Lanjut: Ekstraksi Fitur Domain Frekuensi (Spectral Features)

Slide 6 / 13

Formulasi Fitur Spektral Berbasis FFT Frame

$$\text{Spectral Centroid} = \frac{\sum_{k=0}^{N/2} f_k \cdot |X[k]|}{\sum_{k=0}^{N/2} |X[k]|} \qquad \text{Spectral Rolloff} = \min(f_c) \text{ s.t. } \sum_{k=0}^{k_c} |X[k]| \ge 0.85 \sum_{k=0}^{N/2} |X[k]|$$

📐 Keterangan Variabel & Makna Fisik

  • |X[k]|: Magnitudo koefisien spektrum FFT frame ke-m.
  • f_k: Frekuensi fisik bin ke-k dalam Hertz.
  • Spectral Centroid (Pusat Massa Spektrum): Mengukur derajat 'kecerahan' akustik (brightness/timbre) suatu suara. Suara bernada tajam memiliki centroid tinggi.
  • Spectral Rolloff: Frekuensi batas bawah di mana 85% akumulasi energi spektral terkonsentrasi.
  • Mel-Frequency Cepstral Coefficients (MFCC): Representasi spektrum skala persepsi pendengaran manusia Mel-scale, fitur nomor satu pada Speech Recognition dan Klasifikasi Musik AI.

🔢 Contoh Perhitungan Bertahap

  • Mengapa Fitur Spektral Sangat Penting untuk AI?
  • Memberikan representasi data yang kompak (dimensionality reduction): dari 1000 sampel mentah per frame direduksi menjadi hanya 13 koefisien MFCC bermakna tinggi!
  • Memudahkan model klasifikasi (SVM, Random Forest, CNN) mengenali jenis kerusakan getaran mesin atau emosi suara manusia secara akurat.

Tahap 6: Metrik Kuantitatif Evaluasi Kinerja Pemrosesan

Slide 7 / 13

📌 Signal-to-Noise Ratio (SNR)

  • SNR = 10 * log10( P_signal / P_noise ) dB.
  • SNR Improvement: Delta SNR = SNR_output - SNR_input.
  • Mengukur keberhasilan filter dalam mengangkat sinyal bersih keluar dari derau latar belakang. Kenaikan Delta SNR > 10 dB menandakan pembersihan yang sangat efektif.

📌 Mean Squared Error (MSE)

  • MSE = (1 / N) * sum_{n=0}^{N-1} (x_clean[n] - y_filtered[n])^2.
  • Mengukur derajat kemiripan numerik antara sinyal hasil filtering dengan sinyal referensi murni (ground-truth).
  • Semakin kecil nilai MSE mendekati nol, semakin sempurna restorasi sinyal.

📌 Total Harmonic Distortion (THD)

  • THD = sqrt( sum_{i=2}^inf V_i^2 ) / V_1 * 100%.
  • Mengukur persentase distorsi harmonisa yang timbul akibat ketidaklinieran sistem audio atau perangkat keras.
  • Sistem Hi-Fi berkualitas tinggi menuntut THD < 0.1%.

Implementasi Python: Arsitektur Kelas Pipeline Berorientasi Objek

Slide 8 / 13

📖 Desain Modular SignalProcessingPipeline

  • Membangun kelas Python berorientasi objek (OOP) SignalProcessingPipeline yang membungkus seluruh tahapan pengolahan secara modular.
  • Memudahkan integrasi dengan pipeline pemelajaran mesin (scikit-learn / PyTorch).
  • Mendukung chaining method: pipe.remove_dc().bandpass_filter().extract_features().
Python Implementation (NumPy / SciPy) 
import numpy as np
from scipy.signal import butter, sosfilt, detrend

class DSPPipeline:
    def __init__(self, Fs):
        self.Fs = float(Fs)
        self.sos = butter(4, [100, 2000], btype='bandpass', fs=self.Fs, output='sos')
        
    def process(self, raw_signal):
        # 1. DC Removal & Linear Detrend
        sig_dc = raw_signal - np.mean(raw_signal)
        sig_detrend = detrend(sig_dc)
        
        # 2. Filtering Bandpass Biquad SOS
        sig_filtered = sosfilt(self.sos, sig_detrend)
        
        # 3. Peak Normalization
        sig_norm = sig_filtered / (np.max(np.abs(sig_filtered)) + 1e-9)
        
        # 4. Ekstraksi Fitur Temporal (ZCR & STE)
        zcr = np.mean(np.abs(np.diff(np.sign(sig_norm)))) / 2.0
        ste = np.mean(sig_norm ** 2)
        
        return {
            'clean_signal': sig_norm,
            'features': {'ZCR': zcr, 'STE': ste}
        }

# Uji Pipeline dengan Sinyal Acak
pipeline = DSPPipeline(Fs=8000)
raw_test = np.random.randn(800) + 2.5 # Sinyal bising ber-offset DC
output = pipeline.process(raw_test)
print('Fitur Hasil Ekstraksi:', output['features'])
