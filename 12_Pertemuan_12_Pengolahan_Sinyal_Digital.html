Dunia Filter Digital: Anatomi Spesifikasi Filter

Slide 2 / 13

📘 Mengapa Kita Membutuhkan Filter Digital?

  • Filter digital adalah sistem LTI yang dirancang secara spesifik untuk meloloskan komponen frekuensi yang diinginkan (passband) dan menolak/meredam komponen frekuensi yang tidak diinginkan (stopband).
  • Menghilangkan noise dengung listrik 50 Hz pada rekaman vokal studio.
  • Mengisolasi pita kanal komunikasi tertentu pada penerima software-defined radio (SDR).

🚀 Empat Parameter Toleransi Spesifikasi Filter

  • 1. Passband Cutoff Frequency (wp): Batas frekuensi pita lolos.
  • 2. Stopband Cutoff Frequency (ws): Batas frekuensi pita henti.
  • 3. Transition Band (Delta w = ws - wp): Lebar pita transisi dari lolos menuju henti (semakin sempit, orde filter semakin tinggi).
  • 4. Riak Toleransi (Ripples): Passband ripple delta_p (dB) dan Stopband attenuation delta_s / As (dB).

Keunggulan Mutlak Filter FIR: Linear Phase & Stabilitas

Slide 3 / 13

📌 1. Selalu Stabil Secara Alami

  • Fungsi transfer H(z) = sum_{n=0}^M h[n] z^(-n) adalah polinomial murni tanpa penyebut variabel.
  • Seluruh M pole dari filter FIR terkumpul tepat pada titik origin z = 0.
  • Karena origin selalu berada di dalam lingkaran satuan (|0| < 1), filter FIR TIDAK PERNAH BISA TIDAK STABIL!

📌 2. Linear Phase Murni (Tanpa Distorsi)

  • Dapat dirancang memiliki respon fase garis lurus sempurna: angle H(w) = -alpha * w.
  • Group delay konstan sempurna di seluruh spektrum: tau_g = alpha = M / 2 sampel.
  • Seluruh komponen frekuensi mengalami keterlambatan waktu yang identik, sehingga bentuk pulsa gelombang tidak mengalami dispersi atau distorsi bentuk.

📌 3. Kemudahan Implementasi Perangkat Keras

  • Tanpa loop umpan balik rekursif, struktur pipeline FIR sangat ramah arsitektur paralel GPU dan akselerator DSP MAC.
  • Bebas dari masalah limit cycle oscillations akibat pembulatan register berhingga.

Empat Tipe Filter FIR Fase Linier

Slide 4 / 13

📌 Tipe I & Tipe II (Simetri Genap)

  • Syarat Simetri: h[n] = h[M - n].
  • Tipe I: Orde M Genap (Jumlah tap M+1 ganjil). Bebas digunakan untuk Low-Pass, High-Pass, Band-Pass, dan Band-Stop.
  • Tipe II: Orde M Ganjil (Jumlah tap genap). Memiliki zero paksa pada w = pi (Nyquist), TIDAK BISA digunakan untuk filter High-Pass!

📌 Tipe III & Tipe IV (Simetri Ganjil)

  • Syarat Simetri: h[n] = -h[M - n]. Menghasilkan pergeseran fase 90 derajat (Quadrature).
  • Tipe III: Orde M Genap. Memiliki zero paksa pada w = 0 dan w = pi. Digunakan khusus untuk Differentiator dan Hilbert Transformer.
  • Tipe IV: Orde M Ganjil. Memiliki zero paksa pada w = 0.

📌 Kaidah Pemilihan Desain

  • Untuk merancang Filter Low-Pass standar: Selalu gunakan Tipe I (orde genap) atau Tipe II.
  • Untuk Filter High-Pass: WAJIB menggunakan Tipe I, karena Tipe II melarang respons pada frekuensi tinggi Nyquist.

Metode Perancangan Windowing (Window Method)

Slide 5 / 13

Mekanisme Pemotongan Respons Impuls Ideal

$$h_d[n] = \frac{\sin\big(\omega_c (n - M/2)\big)}{\pi (n - M/2)} \qquad h[n] = h_d[n] \cdot w[n] \quad (0 \le n \le M)$$

📐 Keterangan Variabel & Makna Fisik

  • h_d[n]: Respons impuls ideal yang diperoleh dari Inverse DTFT filter brick-wall (berupa fungsi Sinc yang berlangsung tak terhingga dan non-kausal).
  • omega_c: Frekuensi cutoff filter dalam radian per sampel (wc = 2 pi Fc / Fs).
  • M / 2: Faktor pergeseran waktu agar filter menjadi kausal dengan penundaan M/2 sampel.
  • w[n]: Fungsi window berdurasi berhingga (panjang M + 1 sampel).
  • h[n]: Koefisien filter FIR kausal riil hasil perancangan.

🔢 Contoh Perhitungan Bertahap

  • Langkah 1: Tentukan spesifikasi frekuensi cutoff wc dan orde filter M.
  • Langkah 2: Hitung nilai impuls ideal hd[n] untuk n = 0, 1, ..., M. Pada titik tengah n = M/2, gunakan limit L'Hopital: hd[M/2] = wc / pi.
  • Langkah 3: Pilih fungsi window w[n] (misal Hamming atau Blackman) sesuai spesifikasi atenuasi stopband yang dituntut.
  • Langkah 4: Kalikan hd[n] dengan w[n] elemen-ke-elemen: h[n] = hd[n] * w[n]. Selesai!

Matriks Komparasi Karakteristik Fungsi Window

Slide 6 / 13

📌 Rectangular vs Hann

  • Rectangular: Lebar transisi = 4 pi / M, Atenuasi stopband minimum = -21 dB, Passband ripple = 0.74 dB. (Transisi tertajam, namun peredaman stopband sangat buruk).
  • Hann: Lebar transisi = 8 pi / M, Atenuasi stopband = -44 dB, Passband ripple = 0.05 dB. (Pilihan seimbang untuk pemrosesan audio umum).

📌 Hamming vs Blackman

  • Hamming: Lebar transisi = 8 pi / M, Atenuasi stopband = -53 dB, Passband ripple = 0.02 dB. (Paling populer untuk speech recognition dan telekomunikasi).
  • Blackman: Lebar transisi = 12 pi / M, Atenuasi stopband luar biasa = -74 dB, Passband ripple = 0.002 dB. (Sangat bersih untuk instrumentasi presisi).

📌 Window Kaiser (Fleksibel Adaptif)

  • Menggunakan fungsi Bessel termodifikasi I0(beta).
  • Parameter beta mengatur atenuasi stopband secara kontinu.
  • Orde M dapat diestimasi secara presisi menggunakan Formula Bellanger: M approx (-20 log10(delta) - 13) / (14.6 * Delta f).

Algoritma Optimal Parks-McClellan (Equiripple FIR)

Slide 7 / 13

📘 Kelemahan Metode Windowing

  • Pada metode windowing, riak riak (ripple) pada passband dan stopband tidak seragam: riak paling besar berada di dekat pita transisi dan meluruh mengecil di frekuensi jauh.
  • Hal ini tidak efisien! Energi toleransi terbuang sia-sia.
  • Metode windowing menghasilkan orde filter yang lebih besar dari yang sebenarnya dibutuhkan.

🚀 Solusi Optimal Chebyshev: Parks-McClellan

  • Berdasarkan Teorema Alternasi Chebyshev: Riak dibuat berosilasi dengan tinggi puncak yang sama persis (Equiripple) di seluruh pita lolos dan henti.
  • Menghasilkan ORDE FILTER PALING MINIMUM yang mungkin di dunia untuk memenuhi spesifikasi yang diberikan!
  • Diimplementasikan di Python menggunakan fungsi scipy.signal.remez() (algoritma Remez Exchange).

Implementasi Python: Desain Filter FIR dengan firwin

Slide 8 / 13

📖 Fungsi scipy.signal.firwin

  • scipy.signal.firwin(numtaps, cutoff, window='hamming', fs=Fs) merancang koefisien filter FIR metode windowing secara instan.
  • numtaps adalah jumlah koefisien filter (numtaps = M + 1).
  • cutoff adalah frekuensi batas dalam Hertz (atau rasio normalisasi).
  • Evaluasi respons frekuensi menggunakan scipy.signal.freqz(h, 1.0).
Python Implementation (NumPy / SciPy) 
import numpy as np
import matplotlib.pyplot as plt
from scipy.signal import firwin, freqz

# Spesifikasi Filter Low-Pass FIR
Fs = 8000.0        # Frekuensi sampling = 8000 Hz
F_cutoff = 1500.0  # Cutoff = 1500 Hz
numtaps = 51       # Orde M = 50 (Tipe I, genap)

# Rancang Koefisien Filter FIR Window Hamming
h_fir = firwin(numtaps, cutoff=F_cutoff, window='hamming', fs=Fs)

# Evaluasi Respons Frekuensi
w, H = freqz(h_fir, 1.0, worN=1024, fs=Fs)

plt.figure(figsize=(9, 4))
plt.plot(w, 20 * np.log10(np.abs(H) + 1e-6), 'b-', lw=1.5)
plt.title('Respons Frekuensi Filter FIR Low-Pass 51-Tap (Hamming)')
plt.xlabel('Frekuensi (Hz)'); plt.ylabel('Magnitude (dB)')
plt.axvline(F_cutoff, color='r', linestyle='--', label='Cutoff 1500 Hz')
plt.axhline(-53, color='g', linestyle=':', label='Batas Stopband -53 dB')
plt.ylim([-80, 5]); plt.grid(True, alpha=0.5); plt.legend()
plt.show()
